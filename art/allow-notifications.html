Description

Allow notifications is an arcade game that creates the experience of dealing with notifications from social media apps.

Game Controls

The game is designed to play on both computer and an arcade game machine.

Player 1:
WASD to move
Button 1 (Z) / Button 2 (X)

Player 2:
TFGH to move
