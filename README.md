# Yifei Sun — Portfolio

Static website exported from Webflow.

## Preview locally

Open `index.html` in a browser, or run a local static server from this folder:

```sh
python3 -m http.server 8000
```

Then visit `http://localhost:8000`.

## Publish with GitHub Pages

Push this folder to the repository's `main` branch. In GitHub, open **Settings → Pages**, choose **Deploy from a branch**, then select `main` and `/ (root)`. The site will be available at `https://yfsun0920.github.io/portfolio-wbf/` once Pages finishes publishing.

This is a static Webflow export. Webflow-hosted features such as Ecommerce checkout and forms may require Webflow services and may not work in the exported site.
